# Trail of Cthulhu — Character Generator

Character generator for the **Trail of Cthulhu** role-playing game (GUMSHOE System). It guides you through investigator setup, occupations, skills, and a printable character sheet.

## Features

- **Guided Creation**: Step-by-step process to create your character
- **Explained Mechanics**: Each skill and attribute has a clear description
- **Professional Design**: Style inspired by the covers of Trail of Cthulhu books
- **Responsive**: Works on desktop, tablet, and mobile
- **Print friendly**: Print the character sheet or save it as PDF through the browser

## Usage

- Open the application in your browser
- Follow the steps to create your character
- Complete Setup, Personal Information, Investigative Skills, and General Skills
- Review the summary, then print the character sheet or save it as PDF
